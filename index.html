Snake Water Gun Game

A beginner-friendly Python command-line game where the player competes against the computer using classic Snake, Water and Gun rules. The project uses dictionaries, conditional statements, user input and Python's random module for computer-generated choices and game decisions.

A beginner-friendly Python game where the computer generates a secret number between 1 and 100 and the player keeps guessing until the correct number is found. It demonstrates loops, conditions, functions, user input, exception handling and random number generation with helpful Too Low and Too High hints.

GitHub: AakritiGupta-19/number-guessing-game
